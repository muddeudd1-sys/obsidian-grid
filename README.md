# ⚡ OBSIDIAN // GRID

A high-fidelity, futuristic gaming portal and community hub built with modern front-end web tech.

![Obsidian Grid Banner](https://via.placeholder.com/1200x600/050608/a855f7?text=OBSIDIAN+//+GRID)

## 🔥 Features
- **Cyberpunk UI & Visuals:** Built with Tailwind CSS, custom glow effects, and interactive canvas particle system.
- **Dynamic Armory:** Filter and search games by title or genre in real-time.
- **Community Grid (Forum):** Transmit live forum signals, post threads, and track replies.
- **Real-Time World Clocks:** Live clocks for Tokyo, Los Angeles, and London.
- **Customizable Operator Profile:** Persistent user handle setup.

## 🚀 Tech Stack
- **HTML5 & Vanilla JavaScript (ES6+)**
- **Tailwind CSS** (via CDN)
- **HTML5 Canvas API** (Interactive particle background)
